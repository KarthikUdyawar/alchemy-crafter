# Alchemy Crafter: Decisions

Append-only. Never edit an entry. A changed decision gets a new `D-NNN` that supersedes the old one.

## D-001 Sorted tuple for element pairs

Sprint 1. The pair `(a, b)` is sorted before any cache, DB or AI call. Reason: the same key
whichever order the player types.

## D-002 Cache fails silently

Sprint 1. Redis errors never raise. Reason: a Redis outage must not break gameplay.

## D-003 Strict single-word AI parsing

Sprint 1. The parser accepts one lowercase word only. Reason: keeps element names
substance-like, no compounds or phrases.

## D-004 Ollama timeout default 100s

Sprint 1. `OLLAMA_TIMEOUT` defaults to 100. Reason: allows slow local inference. The conflict
with the documented under-2s AI target is open (Sprint 2 DOC-1).

## D-005 Idempotent DB init with base seeds

Sprint 1. `init_db()` can run on every boot. Reason: safe restarts and the same starting state
for every run.

## D-006 Docs follow the sprint layout

Sprint 2. `ROADMAP.md`, `DECISION.md`, `STRUCTURE.md` and `sprints/Sn/{PRD,TODO}.md` replace
`PRD.md` and `SPRINT_N.md`. Reason: one owner per fact, decisions no longer buried in sprint
docs, same layout as the maintainer's other repository. `STRUCTURE.md` is generated by
`make tree`.

## D-007 One branch per sprint

Sprint 2. Branch `feature/sN-<slug>` per sprint, one commit per TODO task. Reason: fewer
branches and PRs, ticket history lives in commits. Supersedes the one-branch-per-ticket rule.
Sprint 2 keeps `feature/qa-tooling`, opened before this decision.
